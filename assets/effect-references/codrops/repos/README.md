## How to run them
- Static repos (plain HTML): open `index.html` with Live Server or `npx serve`.
- Repos with a `package.json`: run `npm install`, then `npm run dev` or `npm start` (check each repo's README).
- Ask AI: "Read repos/<Name>/ and turn this effect into a React component using GSAP for my project".
