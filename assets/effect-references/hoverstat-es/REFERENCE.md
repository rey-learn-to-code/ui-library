# Hoverstat.es — reference (link only)

- Site: https://www.hoverstat.es/
- Status in this library: **link-only** — no screenshots or page content were downloaded (the images on the site are screenshots of other companies' websites and belong to them).
- Last checked: 2026-10-09

## What this site is good for
- "The home of alternative web design" — a gallery of **experimental, rule-breaking** websites: unusual hover interactions, animated typography, unconventional navigation, artistic portfolios.
- Each entry has a short description pointing out **the interaction worth learning from** + the studio credit.
- Good for: finding unique micro-interaction ideas that are not run-of-the-mill.

## How to browse / filter
- The home page lists entries by posting date; the **Archive** section shows older ones; the Submit section lets you send in a site.
- Read the description to know where the effect is, then open the original site to experience it.

## Notes
- No source code — you can only look at the original site; when asking AI to recreate an effect, describe it in words or record your own screen video so the AI understands.
