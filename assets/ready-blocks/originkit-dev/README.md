# OriginKit (https://www.originkit.dev/) — links only

A library of animated components/sections (WebGL, light backgrounds, hero, pricing, footer...). Free to browse, but the "Get this Component → Copy Code" button calls `https://www.originkit.dev/api/components/<name>/source` and gets error 401 when you are not logged in, so the code CANNOT be downloaded without an account.

## What is inside
- `pages_list.json` — a list of public links taken from the site's sitemap: 546 components, 58 sections, 16 category pages. Use it to browse and pick templates quickly.

## How to use it when building a website
- Open a link from the list to see the demo and the props table (the component's settings).
- To get the code: log in on the site and use the command shown in the "Get this Component" box, in the form `bunx --bun originkit@latest add <name>` (the site has npm/yarn/pnpm tabs with the matching commands), or copy the code/AI prompt from the page.
- License (the /docs/licensing page): you may use it in your own personal/commercial projects, but you may not redistribute it or sell templates that contain the components.

Plain HTML: not directly applicable (React components).
