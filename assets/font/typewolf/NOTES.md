# Typewolf — link only

Link: https://www.typewolf.com/

Typewolf is a reference site: every day it features a well-designed website and says exactly which fonts it uses and how the heading and body fonts are paired. Its articles are copyrighted by Typewolf, so they are **not copied into this library**.

## How to use it
1. Open the home page or the "Site of the Day" section and look through the sample websites; note down the font pairs (heading + body) you like.
2. Typewolf's "Google Fonts" / "Free Fonts" sections suggest free fonts — prefer these.
3. Many fonts on Typewolf are **paid fonts**. For a paid font, find a free font with a similar look in `../google-fonts/fonts-vietnamese.json`.
4. Always check that a font supports Vietnamese diacritics before using it (see `../README.md`, section 4).
5. Free, Vietnamese-capable font pairs suggested by this library are in `../font-pairings-vietnamese.md`.
