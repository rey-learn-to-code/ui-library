- `prompts-index.json` (this folder): the combined index. The `site` field names the source site, `tier` names the plan (Free/Premium/Pro/Paid), `has_prompt_text` says whether the prompt was saved, and `file` points to the detailed .md file.
- Each site has its own `README.md` explaining its license and how to use it.
- Preview images and videos are saved as links only, not downloaded.
- Saved prompts are for internal use only, to build websites for your own projects. Do not repost or resell them.
