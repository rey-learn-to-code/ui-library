# GetLayers (getlayers.ai) — prompt template index

Source: https://www.getlayers.ai/ — a library of "prompts" for building templates, 3D scenes, sections, backgrounds and WebGL gradients (Textura Agency).

## Collected (2026-10-09)
- 552 items in `prompts/` + `prompts-index.json` (title, type, tags, Free/Premium plan, preview image/video links — images NOT downloaded).
- Listing sources: the public list pages (/templates, /3d-scenes, /sections, /backgrounds, /gradients) + sitemap.xml (/layer/*).
- The site says "1,088 gradients" because each gradient has many variants (e.g. soffit-001…); this index records the main items shown in the lists/sitemap and does not list every variant.

## Prompt content
- Premium: needs a paid plan. Free: casual visitors can copy only a very few times per day before a login is required → marked "login required".
- 2 public prompts (setting up a Next.js + Claude starter and AI Design Vault) are shown openly on the site → saved in full (`prompts/public-*.md`).

Terms (https://www.getlayers.ai/terms-of-use): a license to use the prompts is granted when you buy a plan; scraping/copying/redistributing the prompt library is forbidden. This library keeps only metadata + links for internal lookup.

## How to use
Filter `prompts-index.json` by `category`/`tags`/`tier` → open the `url` → adjust the settings on the page → "Copy prompt" (log in if needed) → paste into Claude/Cursor.
