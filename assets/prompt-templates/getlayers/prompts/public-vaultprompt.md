## Prompt

```text
Please clone https://github.com/textura-agency/ai-design-vault into this project as a reference vault — do not restructure the app around it. Read its README first; it is the map. From then on, follow its notes on layout, typography, colour, spacing and motion whenever you build or change UI here, and tell me when something I ask for contradicts them. It is stack-agnostic: apply the judgement, not the file structure.
```
