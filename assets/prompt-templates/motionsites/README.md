# MotionSites AI (motionsites.ai) — prompt template index

Source: https://motionsites.ai/ — a library of prompts for building animated landing pages/sections (hero, footer, CTA, pricing…), with background videos.

## Collected (2026-10-09)
- 561 items (Free: 193, Premium: 368) in `prompts/` + `prompts-index.json`.
- The list comes from the same public query the home page uses to show its template grid (title, type, free flag, preview link). The prompt content field was not queried.
- Each item opens directly at `https://motionsites.ai/?prompt=<slug>`.

## Prompt content
- Free items: the site lets you click "Copy full prompt" without logging in. However, the terms (https://motionsites.ai/terms) clearly say: no scraping / bulk automated access, and no redistributing or reposting prompts. So only 1 sample prompt, copied by hand, is saved (`prompts/wayfinder.md`); the other Free items include instructions to open the link and copy when needed.
- Premium items: need a login + a paid plan.

## How to use
Filter `prompts-index.json` by `tier == "Free"` and `category`/`tags` → open the `url` → "Copy full prompt" → paste into Claude/Cursor/Lovable, and replace the brand name, content and video with your project's. The website you build belongs to you; do not share the prompt word for word.
