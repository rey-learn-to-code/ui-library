# Aura (aura.build/templates) — template index

Source: https://www.aura.build/templates — a library of landing page templates made by the community with the Aura AI builder (HTML/Tailwind, some React).

## Collected (2026-10-09)
- 5667 templates (Free 4952, Pro 582, Paid 133) in `prompts/` + `prompts-index.json`.
- The list comes from the same public query the /templates page uses for its display (featured, public templates with ≥50 views), with only the visible fields: title, description, tags, category (Web/Mobile/Animation), plan, preview image (link).
- Each template has a link to its detail page and a live preview link `https://<slug>.aura.build`.

## Prompt content
The "Copy prompt" and "Use for Free" buttons both require a login (checked with a Free template) → every item is marked "login required". No prompt is shown publicly.

## How to use
Filter by `category`/`tags`/`tier` → open the live preview to see the layout → use it as a reference with the sample prompt in `../../PROMPT_EXAMPLES.md` (the "learn from a reference URL" section), or log in to Aura to remix it.
